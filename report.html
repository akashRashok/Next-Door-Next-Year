The buyer decision

The primary user is an owner-occupier comparing City of Sydney apartments where daylight or outlook affects a shortlist. A listing can describe an apartment as bright today while a nearby site has an existing consent and a larger proposal under assessment. The panel gives the buyer an official record to inspect and a useful question to take to inspection.

How it works

  1. The buyer opens the side panel on an individual realestate.com.au or Domain property page and chooses to read its address, or enters an address manually.
  2. The local server resolves address candidates through Microburbs. A unique exact unit match permits a bedroom fact; ambiguity or a postcode mismatch suppresses it.
  3. The server requests the property point and recent suburb DA feeds, then calculates straight-line distance and compass direction to sites within 300 m.
  4. A reviewed crosswalk supplies official references, stages, and links. Unlinked Microburbs rows stay labelled as unverified candidates, and consent and proposal records stay separate.

The API key stays in the local Node process. The browser sends only the address the user chooses to check. Recent development feeds and the curated crosswalk do not provide exhaustive planning coverage.

Matching evidence

Ten-address held-out check, 7 November 2026: 7 exact unit matches, 0 building-only matches, 3 safe abstentions, 0 wrong-unit matches, and 0 API errors. Exact yield was 7/10. The 80% target among independently verifiable units remains unconfirmed because the unmatched listing addresses lack independent GNAF truth.

The ten public listing addresses were selected after implementation and were not used in the matcher tests. One earlier four-digit-unit parser error was fixed before the final run. The three final abstentions involved a 551 Elizabeth Street listing whose GNAF candidate uses 543–551, a G01 Euston Road listing without a same-street candidate, and an A309 Geddes Avenue listing with no geocoder candidate. The matcher did not guess across those discrepancies.

Limits and sources

The project crosswalk is a curated sample. Sites without a defensible coordinate are omitted; an empty result does not mean no project exists. Candidate rows may lack an official reference or stage and are not treated as verified. Planning status and documents can change. The panel does not model views, shadow movement, construction timing, or property value.
