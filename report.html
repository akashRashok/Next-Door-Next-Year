The buyer’s decision

The primary user is an owner-occupier comparing City of Sydney apartments where daylight or outlook affects a shortlist. The panel first establishes the address and match scope, then shows up to three nearby sites. It never predicts a unit’s future sunlight from distance alone.

How it works

  1. The buyer opens the side panel beside a realestate.com.au listing or enters an address manually.
  2. The local server resolves candidates through Microburbs. Only a unique exact unit match permits a bedroom fact. Postcode disagreement stops the lookup.
  3. The server retrieves the property’s coordinates and recent suburb DA records. It measures straight-line distance and compass direction.
  4. A reviewed crosswalk supplies official references, status and links for ten residential SSD records. Unlinked Microburbs rows remain labelled candidates. Consent and proposal records stay separate.

The API key stays in the local server. The browser sends only the chosen address. Microburbs development feeds are recent and bounded; state projects may be absent.

The Waterloo case

The 102/2 Sam Sing Street listing describes an east-facing, light-filled unit. The protected Microburbs demo resolves it as GNAF GANSW719665322 with one bedroom; it returns no AVM. The product still requests the fact live during use.

The City consent D/2021/1415 and state proposal SSD-95997711 refer to 903–921 Bourke Street. The state page describes the existing six buildings with 376 apartments and a request for approximately 250 additional apartments. Its status was Assessment when checked on 7 November 2026; this proposal is not an approval.

Inspection question: Do the official planning documents assess shadows at this building, and what do they show for the apartment’s windows and balcony? The site is northwest of the listing building on the checked map points. Geometry alone does not establish a daylight effect.

Matching evidence

Ten-address held-out check, 7 November 2026: 7 exact unit matches, 0 correct building-only results, 3 safe abstentions, 0 wrong-unit matches, 0 API errors. The ten addresses came from current realestate.com.au listings selected after implementation; none were used in the matcher tests. Overall exact yield was 7/10. The three abstentions remain in the denominator; this run does not establish the 80% verifiable-unit target because independent GNAF truth for the unmatched addresses is unavailable.

One abstention exposed a four-digit-unit parser error; it was fixed before this final run. The remaining abstentions were a listed 551 Elizabeth Street unit whose GNAF candidate uses 543–551, a G01 Euston Road listing without a same-street candidate, and an A309 Geddes Avenue listing with no geocoder candidate. The matcher did not guess across those discrepancies.

Limits

The crosswalk is a curated sample. Sites lacking a defensible coordinate are omitted; an empty result does not mean no project exists. Candidate rows may lack official reference and status, so they are not treated as verified. Planning status and documents can change. The panel does not model views, shadow movement, construction timing or property value.
