# Pitch stage

This is the source for the narrated `pitch.mp4`. It uses the Stageshow React kit, the project's listing photo, and the product panel's colors and content. `narrate.py` generates the Australian English voiceover aligned to the five scenes.

From `demo-stage`, install dependencies with `npm install`. From `demo-stage/pitch`, start `../node_modules/.bin/vite --config vite.config.ts`, then run `node render.mjs`. The renderer generates the voice and writes `pitch.new.mp4` at the repository root. Review the new file before replacing the old one.

The video is an authored product illustration. It does not represent a live extension run or a unit-level daylight prediction.
